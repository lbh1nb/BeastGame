# 收藏物品素材说明（交 work 端生成）

本项目「兽了个兽」的收藏册从「收藏小动物」改为「收藏与小动物相关的可爱物品」。
游戏内已通过 `src/game/collection-item.ts` 定义了 56 个动物 → 可爱物品的映射，
本目录（`resources/collection/`）存放这 56 件物品的图片，供收藏册与结算掉落弹窗展示。

## 交给 work 端生成的内容

在**本目录**下生成 **56 张**物品图片，文件名与 `{animal}_item.png` 完全一致。

### 文件规格（必须遵守）

- 文件格式：PNG，**透明背景**
- 尺寸：建议 `512×512`（或至少 `256×256`），物品居中构图
- 风格：**Q 萌可爱卡通**，明亮配色，与动物像素卡牌风格统一
- 描边：物品主体带**清晰的深色外轮廓**（与卡牌 1px 黑色描边风格呼应），保证在浅色底上辨识度高
- 质感：柔和高光 + 阴影，圆润可爱，避免写实/恐怖
- **填满画布（重要）**：物品在画布内应尽量占满，主体约占画幅 **90%~95%**，四周透明留白尽量少（≤5%），这样在收藏册展示框里物品才能尽量填满相框，不会显得偏小。请勿留大片透明边距。
- 备注：收藏册详情弹窗会放大展示同一张图，因此主体务必清晰、细节完整，放大后不糊不虚。

### 命名规则

`{animal}_item.png`，`animal` 为英文字母小写，与下方清单的键完全一致。
