# 🐑 兽了个兽

> Q萌卡通风格的消除类桌面小游戏 · Electron + Vue 3 + TypeScript + SQLite · v1.3.0

---

## 📖 项目简介

「兽了个兽」是一款仿"羊了个羊"的消除类小游戏，采用 Q萌卡通风格，支持多模式玩法、闯关系统、道具系统、成就系统。

### 核心特性

- **四种游戏模式**：经典3消 / 四消模式 / 闯关模式 / 挑战模式
- **30关大型闯关**：6章节 × 5关，每章末尾为 Boss 关，全部关卡限时
- **6种章节主题**：家畜 / 野兽 / 森林 / 小动物 / 海洋 / 综合，共56种Q萌动物
- **5种章节机制**：闹脾气 / 藤蔓 / 贪睡 / 躲猫猫 / 气泡，增加策略深度
- **多维星级判定**：由分数 / 剩余时间 / 道具使用 / 剩余点击综合评定 0~3 星
- **道具系统**：撤回 / 洗牌 / 提示 + 4种金币新道具（拆牌锤 / 槽位清空 / 一键配对 / 临时扩容）
- **金币店铺**：通关与挑战获得金币，在商店购买4种新道具
- **56件可爱收藏物品**：每只动物对应一件专属物品，通关后按星级随机掉落，可入收藏册收集，重复品自动转金币
- **挑战模式**：金币门票入场，随机动物+机制+限时，通关返门票并掉落奖励
- **全量统计**：分数 / 连击 / 时长 / 消除数，本地排行榜
- **成就系统**：闯关成就 + 分数成就，共14个
- **全套音效**：3种BGM循环 + 13种SFX + 6档连击夸赞音效 + 游戏内统一温和风铃音效 + 加载界面56种动物叫声（点击触发）
- **解压即玩**：无需安装依赖、软件、环境变量，双击 exe 即可运行

## 🚀 快速开始

### 玩家使用（解压即玩）

**下载地址**：[GitHub Release v1.3.0](https://github.com/lbh1nb/BeastGame/releases/tag/v1.3.0)

1. 点击上方链接，下载 `BeastGame-portable.zip`（约 120MB）
2. 解压到任意目录
3. 双击 `BeastGame.exe` 即可运行

> **无需安装任何依赖、无需配置环境变量、无需 Node.js**
>
> 存档位置：`%APPDATA%\BeastGame\data.db`（删除游戏文件夹不影响存档）

### 开发者指南

#### 环境要求

- Node.js >= 18
- npm >= 9
- Windows 10/11 x64

#### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

#### 打包

```bash
# 编译 + 打包为解压版文件夹（输出到 release/win-unpacked/）
npm run build:win

# 交付物：release/win-unpacked/ 文件夹
# 压缩后即可分发给玩家
```

#### 类型检查

```bash
npm run typecheck
```

## 🎮 玩法说明

### 经典3消

- 点击图案放入底部槽位
- 集齐 **3个相同动物** 即可消除
- 槽位共 **8格**，填满即失败
- **180张牌** 全屏单大堆 **8层** 堆叠，画面充实
- 连击得高分

### 四消模式

- 需要集齐 **4个相同动物** 才能消除
- 槽位 **9格**
- **240张牌** 全屏单大堆 **8层** 堆叠
- 难度更高，得分更多

### 闯关模式

- 共 **6章 30关**，逐关解锁，**全部关卡限时**（超时未通关即判负）
- 前五章统一：L1 90张/6层 → L2 150张/7层 → L3 210张/10层 → L4 240张/10层 → Boss 312张/10层
- 第6章难度增加：210→270→330→360→468张，层数 9→13
- 每章第5关为 **Boss 关**，限时最短（5章限时依 L1 最长 → Boss 最短递减）
- L1用4种动物入门，L2起用6种动物 + 章节机制（L3起）
- 通关获**多维星级评价**（0-3星）：综合分数、剩余时间、道具使用、剩余点击评定
- 星级越高，掉落收藏品越稀有；综合评分达标额外奖励道具

### 道具说明

| 道具 | 图标 | 效果 | 获取 |
|---|---|---|---|
| 撤回 | ↩ | 取消上一次点击操作 | 每局固定发放 |
| 洗牌 | 🔀 | 重新打乱牌堆中剩余图案 | 每局固定发放 |
| 提示 | 💡 | 高亮一组可消除的相同图案 | 每局固定发放 |
| 拆牌锤 | 🔨 | 直接移除一张可点击的牌（含被机制困住的） | 商店购买 |
| 槽位清空 | 🧹 | 一键清空当前槽位所有牌回牌堆 | 商店购买 |
| 一键配对 | 👯 | 直接消除场上某一对同动物牌 | 商店购买 |
| 临时扩容 | ➕ | 本局额外 +1 卡槽 | 商店购买 |

> 撤回/洗牌/提示每局固定发放；4种新道具通过**商店**用金币购买，进入闯关/挑战后可用。

### 商店 / 收藏 / 挑战

- **商店（🛒 Shop）**：用金币购买 4 种新道具。金币来源：通关按星级奖励（1星50 / 2星100 / 3星150）、挑战奖励、出售重复收藏品。
- **收藏册（🎨 Collection）**：56 件可爱收藏物品（每只动物对应一件，如绵羊→毛线球、猫咪→逗猫棒），通关后按星级随机掉落，**优先掉落尚未收集的物品**；重复掉落自动转金币（普通80 / 稀有200 / 史诗400 / 传说800）。掉落带下落弹跳动画与稀有度光晕。收藏册为**相册风格**：按 6 章分组，章节头带代表性小动物头像与装饰，物品图片尽量填满相框；**点击任意收藏品**可弹出详情界面（大图 + 名称 + 稀有度 + 文字描述 + 收集状态）。
- **挑战模式（⚡ Challenge）**：消耗 100 金币门票入场，随机组合动物 + 随机机制 + 限时；通关返还门票，并稳定掉落收藏品与额外道具；失败门票不返还。

### 星级评定

- 仅**通关**参与星级，失败恒为 0 星。
- 星级 = 分数 ×（0.4 + 0.2×时间系数 + 0.2×道具系数 + 0.2×点击系数），映射到 0~3 星：
  - ≥ 0.85 → 3星，≥ 0.6 → 2星，≥ 0.3 → 1星，否则 0 星。
- 分数决定星级上限；剩余时间越多、道具用得越少、剩余点击越多，星级越高。

### 综合评分奖励

游戏结束时的综合评分 = 基础分×0.5 + 连击奖励 + 时间奖励

| 总分阈值 | 奖励 |
|---|---|
| ≥ 800 | +1撤回 +1洗牌 |
| ≥ 1500 | +1提示 |
| ≥ 2500 | +1撤回 |

## 🎨 视觉设计

- **风格**：Q萌卡通
- **主色**：橙黄 `#ffb84d`
- **背景**：暖米色 `#fff5e1`
- **窗口**：竖版 800×1200（手机比例）
- **动物图案**：56种 Q萌动物，使用真实图片素材（`resources/animals/static` 静态图 + `active` 悬停动态图），加载时自动抠透明背景并裁剪主体，每种动物辨识度高、特征鲜明
- **选关地球**：闯关模式选关页采用 **真3D球体地球**（Three.js WebGL），使用 AI 生成的卡通等距圆柱贴图（`resources/earth_texture_cartoon_v9.jpg`），左右边缘无缝融合 + 极点融合消除畸变，旋转不割裂，带半透明云层、大气光晕、星空背景与 6 章节 emoji 标记，可拖动旋转 / 点击标记进入章节

## 📦 解压即玩说明

本项目采用 **解压版文件夹** 打包方式，玩家无需安装任何依赖：

1. **Node.js 运行时**：Electron 自带，不需系统安装
2. **Chromium 浏览器**：Electron 自带
3. **SQLite 数据库**：`sql.js`（纯 JavaScript，无需原生模块），WASM 文件随包附带
4. **音效**：真实音频文件 + Web Audio API 程序化回退；图片资源打包进 `resources/`
5. **配置文件**：首次启动自动生成到 `%APPDATA%\BeastGame\`
6. **环境变量**：完全不依赖
